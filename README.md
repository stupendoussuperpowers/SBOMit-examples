## SBOMit-examples

Example attestations and SBOMs generated using [in-toto/witness](https://github.com/in-toto/witness) and [SBOMit](https://github.com/SBOMit/sbomit). 

## Example Directory Structure

```
- <source>  // Source of the example project
- README.md // Build and attestation instructions.
- <project>-attestation.json // Readable witness attestation.
- <project>-sbom.json // in-toto enriched SBOM.
```
